# Audit Log Project

This repository holds the code for the Audit Log Project.

The following informative files are available:

- `README.md`: this file;
- `projects.{org,pdf}`: the project proposal, updated as the project progresses;
- `notes.{org,pdf}`: notes taken during the project, updated as the project progresses;
- `queries.{org,pdf}`: actionable Orgmode sources that generated the datasets used in the project;

The rest of the repository is in very heavy development and will be indexed here later.
